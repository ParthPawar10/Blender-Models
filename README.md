# BlenderModels

This repository contains a collection of 3D models created using **Blender**, the open-source 3D creation suite. The models range from basic geometry and animations to detailed environments and characters, showcasing various modeling, texturing, lighting, and rendering techniques.

## Contents

- **.blend files** of each model
- Exported formats (e.g., `.fbx`, `.obj`, `.glb`) for external use
- Textures and materials used in the scenes
- Renders and preview images

## Purpose

The goal of this collection is to:

- Practice and improve 3D modeling and animation skills
- Serve as a portfolio of Blender work
- Provide assets for use in personal or educational projects
- Explore Blender’s powerful tools, including:
  - Sculpting
  - Geometry nodes
  - Shader editor
  - Animation and rigging
  - Lighting and rendering (Eevee/Cycles)

## Usage

All models in this repository are free to use for **educational** or **non-commercial** purposes unless otherwise specified. Please give credit if you use them in your own projects.
